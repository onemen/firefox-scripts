:::note
Since Firefox removed the internal component that loads _legacy_ extension, in order to install
**Tab Mix Plus**, or any other _legacy_ extension, you have to install 3rd party helper scripts.<br/>
:::

:::tip
If you are using **Waterfox** browser, it ships with a built-in **Bootstrap Loader**, so you only
need to install the `firefox-scripts` configuration files if you use `userChromeJS` scripts.

<details>
<summary>What is userChromeJS?</summary>

[userChrome.js](how-it-works/userchrome-js/) is the script loader that finds your `.uc.js` files
in the profile's `chrome` directory, reads their headers, and runs them in every browser window.
`userChromeJS` is the name of the broader mechanism and the original project behind it; Firefox
removed the internal component that loaded these files, so both legacy extensions like **Tab Mix Plus**
and `userChromeJS` scripts need helper scripts installed to load them.

- If you only want to customize the browser appearance with `userChrome.css`, **Waterfox**'s
  built-in Bootstrap Loader or a plain `userChromeJS` loader may be all you need.
- If you want to use **Tab Mix Plus** or other legacy extensions, follow the
  [installation steps](#install-firefox-scripts) below.

</details>
:::

## Install Firefox Scripts

Please follow the instructions below step-by-step to install the scripts. The extension will not
work if you install any files in the wrong location.

### Installer and updater

**firefox-scripts** installs and keeps the helper scripts up to date — a small native installer
copies the two packages into the browser, and an in-browser updater keeps them current
automatically as new versions are released.

#### The installer

Download the installer for your OS from the
[firefox-scripts releases page](https://github.com/onemen/firefox-scripts/releases/tag/latest):
`installer_win.exe` (Windows), `installer_linux` / `installer_linux_aarch64` (Linux), or
`installer_mac` (macOS).

Run the downloaded installer. It connects to a running Firefox-family browser (Firefox, Waterfox,
Zen Browser, LibreWolf, or Floorp), opens an install screen in a browser tab, and lets you pick
which browser to set up.

:::note
The installer is currently **unsigned**, so on Windows **SmartScreen** may show
_"Windows protected your PC"_ on first run — click **More info** and then **Run anyway** to
continue, and approve the single **UAC prompt** if it appears (one checksum-verified elevation,
for the copy step only).
:::

Choose the components to install:

- **Configuration files** (`config.js`, `config-prefs.js`) — copied to the browser's installation
  directory.
- **Utils** (the chrome scripts) — copied to your profile's `chrome/utils/` directory.

Click **Install**, wait for completion, then **Restart the browser** when prompted.

The installer is a one-shot setup tool: it installs only the components you pick and **does not**
leave behind any other files, background processes, or scheduled tasks. After the install completes
you can delete the downloaded executable — nothing else was installed besides the configuration
files and scripts you chose.

#### The updater

Once installed, the scripts keep themselves current without you re-running the installer:

  href="https://raw.githubusercontent.com/onemen/firefox-scripts/main/docs/screenshots/updater.png"

- **Daily check.** The updater (a small privileged script that lives inside the browser) checks
  once a day whether a newer version of the scripts or configuration files has been published.
- **Notification tab.** When an update is available, the updater opens a tab showing what would
  change. You can install the update right there, skip it for the day, or permanently ignore a
  specific update.
- **In-tab install.** Applying an update downloads the new packages and copies them into place
  inside the browser — no installer download needed. Updating the configuration files, which live
  in admin-protected folders (e.g. Program Files on Windows), triggers a single elevation prompt
  via a small helper that ships with the update.
- **Manual update.** You can always open the updater manually from the browser menu, or download
  the `utils.zip` / `fx-folder.zip` packages directly from the update tab.

Prefer to install by hand? Follow the download and installation steps below.

### Download latest scripts

It is recommended to check periodically, or at least with every Firefox update, if new `Firefox Scripts` are available.
You should download the latest version of the scripts from the links below.

- Download [configuration files][FX_FOLDER]
- Download [utils][UTILS_EXTENSIONS_AND_SCRIPTS]

`utils.zip` and `fx-folder.zip` are published with every build on the
[firefox-scripts](https://github.com/onemen/firefox-scripts) repository — the links above always
point at the latest build.

<Aside type="caution">
  The original scripts were created by [@xiaoxiaoflood](https://github.com/xiaoxiaoflood), but the
  [firefox-scripts repository](https://github.com/xiaoxiaoflood/firefox-scripts) is no longer
  maintained, and the code may be outdated.
  <br /> Always use firefox scripts from the links above.
</Aside>

### Install config script

Open `about:support` and locate the path to your **Application Binary** and **Profile Folder**<br/>
![about-support](https://user-images.githubusercontent.com/3650909/192940048-0115c26a-81c0-4343-9f5e-164012420af2.png)

:::note
`Application Binary` folder Is `Firefox root directory` (the folder that contains `firefox.exe`).
for clarity, this text uses the terms **Firefox root directory**<br /> `Profile Folder` is where
Firefox stores your bookmarks, passwords and other user data. You can find more information about it
in [this article](https://support.mozilla.org/en-US/kb/profiles-where-firefox-stores-user-data)
:::

Copy [configuration files][FX_FOLDER] to
your **Firefox root directory**.<br/> `fx-folder.zip` files are packed with paths used by Firefox
for `Windows`, `Linux` and `macOS` users should follow the instructions below. the `zip` file
contain the following files:

- `config.js` - This file should be copied to the directory that contains `firefox.exe`, referred to
  as `PATH TO FIREFOX.EXE`.
- `config-prefs.js` - This file should be copied to `[PATH TO FIREFOX.EXE]/defaults/pref`.

### Install utils

Remember, the **utils** script needs to be installed separately in each profile where you want to
use **Tab Mix Plus**. This differs from the main `config` script, which only requires installation
once in your Firefox root directory (containing firefox.exe). The reason for this distinction is
that each profile maintains its own settings and data, and the utils script plays a vital role in
ensuring **Tab Mix Plus** works seamlessly within each individual profile.

<Steps>

1. Locate your **Profile Folder** as described in the previous step.

2. Create `chrome` folder in your **Profile Folder** (if one does not exist).

3. Extract
   [utils][UTILS_EXTENSIONS_AND_SCRIPTS]
   folder inside the `chrome` folder, the result should be `[PROFILE_NAME]/chrome/utils`, all the
   files should be in the `utils` folder (see the screenshot below).<br />
   Make sure all the files you see in the screenshot below are in the `utils` folder and that `utils` folder is inside `chrome` folder.

4. Open **about\:support** page and click `Clear startup cache…` to force Firefox to load the
   installed scripts on the next startup.

</Steps>

## Removing the scripts

1. Remove `config.js` and `defaults/pref/config-prefs.js` from the Firefox root directory.
2. Remove the `chrome` folder from each profile (or just `chrome/utils` if you only want to drop
   the shipped scripts and keep any of your own `chrome/` files).
3. Restart the browser.

The updater goes away with the utils, so nothing will try to re-install anything. If you still have
`config.js` and `config-prefs.js` in the browser root after this, Firefox will still try to run
AutoConfig on the next start — remove those too, or it will log that `config.js` is missing.

## Browser compatibility

These scripts are validated on every release in CI against the browsers below. Anything not listed
here may work, but is not covered by the release gates.

| Browser | Notes |
| ------- | ----- |
| Firefox (stable, ESR, Developer Edition, Nightly) | Fully supported. Nightly is the leading edge — see the current Nightly version below. |
| Waterfox | Ships its own Bootstrap Loader, so ours skips loading it (loading both would double-register and break legacy add-ons). `userChrome.js` and the updater still work. |
| Zen Browser | No special handling needed. |
| LibreWolf | No special handling needed. |
| Floorp | No special handling needed. |

A browser must be **running** when the installer runs — detection uses process scanning and lock-file
inspection.

:::note
The latest Firefox Nightly this was tested against is **Firefox Nightly 159**. To keep this number
current automatically, wire it from the same source the TabMixPlus docs use (see
`tabmixplus-docs/src/utils/helper.mjs` for the pattern) — that is a follow-up, not done here.
:::

## In three steps

1. **Download the installer** for your OS from the [latest release](https://github.com/onemen/firefox-scripts/releases/tag/latest).
2. **Run it** and pick the browsers and components to install in the tab it opens.
3. **Restart the browser.** From then on, updates arrive on their own.
