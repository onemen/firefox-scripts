## What it is

Firefox removed the component that loaded **legacy add-ons** (`install.rdf` +
`bootstrap.js` extensions such as [TabMixPlus](https://github.com/onemen/TabMixPlus)). Firefox
Scripts puts that capability back, and adds a **userChromeJS** loader so you can drop your own
`.uc.js` scripts into the browser.

Two packages do the work:

- **`fx-folder.zip`** — configuration files copied **once per browser install**, next to the
  browser binary.
- **`utils.zip`** — the chrome scripts, copied **into every profile** that should use them.

A small native installer copies both, and a privileged script inside the browser checks once a day
whether newer versions have been published.

## In three steps

<Steps>

1. **Download the installer** for your OS from the [latest release](https://github.com/onemen/firefox-scripts/releases/tag/latest).
2. **Run it** and pick the browsers and components to install in the tab it opens.
3. **Restart the browser.** From then on, updates arrive on their own.

</Steps>
