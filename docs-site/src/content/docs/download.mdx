:::note[About the dates]
Packages are **dated, not version-numbered**: every publish stamps each package with the date its
content last changed (`YYYY-MM-DD`, UTC). That is why `fx-folder` can show an older date than
`utils` — it simply has not changed since.
:::

Download the files for the dated release you want and install them by hand — unpack a package zip
over the existing files (or use the updater tab's manual-download link). The next daily check will
offer the newer version again; use the tab's **skip** option if you want to stay on the older build.
